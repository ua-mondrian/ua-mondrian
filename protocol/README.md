# Протокол исследования

- `План статьи.docx` — протокол UA-Mondrian v1.0. В нём заданы гипотеза H1 и критерии её подтверждения, наборы данных и роли признаков, веса R_rep, параметры α, β, k и ℓ, правила сидов, гиперпараметры классификаторов, метрики и статистический тест. Документ публикуется без изменений, иначе его хэш не совпал бы.
- `SHA256SUMS.txt` — файл хэшей, записанный авторами 01.11.2026. Вторая строка относится к рабочей таблице с обзором литературы; эта таблица в репозиторий не входит.

Проверка (из каталога `protocol/`):

```bash
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
# План статьи.docx: OK
```

## Что подтверждает и чего не подтверждает хэш

Пилот выполнен 11.11.2026, полный прогон — 11–12.11.2026. Метаданные документа: создан 31.10.2026, последнее изменение — 01.11.2026.

Протокол не депонировался в публичном реестре до эксперимента. Этот репозиторий опубликован позже. Поэтому совпадение хэша доказывает только то, что документ не менялся с момента публикации. Дату его фиксации (01.11.2026) указывают авторы.

В свойствах и тексте документа он назван «предварительно зарегистрированным». Под этим подразумевалась фиксация протокола до эксперимента, а не публичная регистрация.

Чем реализация и анализ отличаются от протокола, перечислено в разделе «Отступления от протокола» корневого [README](../README.md).
